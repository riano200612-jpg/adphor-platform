# Glosario técnico ADPHOR

| Término | Uso en el proyecto |
| --- | --- |
| ADPHOR | Nombre oficial de la plataforma |
| Miss ADPHOR | Asistente virtual; no equivale a proveedor de IA verificado |
| QA Integral | Rama de integración y trabajo de calidad |
| PR | Pull Request: propuesta de cambio revisable |
| SHA | Identificador de commit Git |
| CI | Comprobaciones automatizadas del repositorio |
| E2E | Prueba de extremo a extremo, por ejemplo Playwright |
| IAM | Gestión de identidad y permisos |
| MFA / AAL2 | Autenticación multifactor y segundo nivel de garantía |
| RLS | Políticas de seguridad por filas PostgreSQL |
| PQRS | Peticiones, quejas, reclamos y sugerencias |
| Copropiedad | Ámbito de datos que necesita aislamiento por autorización |
| Storage privado | Archivos sujetos a permisos y enlaces temporales |
| Contrato | Entrada, salida y reglas de una interfaz de software |
| Dato sintético | Fixture de prueba, no hecho operativo del cliente |
| SHA de rama | Referencia concreta que permite reproducir una revisión |

Convenciones editoriales: **ADPHOR**, **Miss ADPHOR**, **QA Integral**, **copropiedad**.
