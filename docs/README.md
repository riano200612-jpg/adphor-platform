## Reglas para interpretar la documentación

1. Identifique la **rama + SHA** antes de evaluar una característica.
2. Distinga **código**, **prueba aislada**, **verificación autenticada** y **aceptación del cliente**.
3. Consulte [QA Integral](https://github.com/riano200612-jpg/adphor-platform/tree/qa/integral-claude-reviewed-20261111) y [solicitudes abiertas](https://github.com/riano200612-jpg/adphor-platform/pulls) para comprobar los cambios posteriores a cualquier informe.
4. Los informes históricos en `docs/` y `qa/` se conservan sin reescritura retroactiva.

Esta mejora no mueve ni renombra código, no altera credenciales ni modifica fuentes originales.
